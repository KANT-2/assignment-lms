## 2. 적용 정책 (`GradingPolicy` 기본값)

```
최종 = 성취도 × 0.7 + 성실성 × 0.3
성취도 내부:  개인:팀 = 0.7 : 0.3      선택:필수 = 0.6 : 0.4
과제 하한:    필수 40 · 선택 20
미제출:       필수 10점 · 선택 0점
지각:         튜터점수에서 late_penalty 차감 (하한 적용 후)
중요도 배수:  상 1.5 / 중 1.0 / 하 0.5   (같은 버킷 내 가중평균)
미채점(제출O·점수X): 성취도에서 제외
```

버킷 = `(is_team) × (is_required)` 4개. 활성 버킷만 base 가중치를 정규화해서 합산.

```
base:  (개인,필수)=0.7×0.4=0.28   (개인,선택)=0.7×0.6=0.42
       (팀,필수) =0.3×0.4=0.12   (팀,선택) =0.3×0.6=0.18
```

## 4. 대조 결과

### [A] `grading.compute` ↔ `RoundScore` — 25명 전원 일치

스냅샷이 실시간 계산값(`total` / `achievement` / `sincerity` / `graded_count` /
`ungraded_count` / `total_count`)을 **그대로** 박제함을 확인.

### [B] full (id 21) — 손계산 일치

```
A1: 90, 정시 → max(40, 90)=90            버킷(개인,필수), w=1.0
A2: 80, 정시 → max(20, 80)=80            버킷(개인,선택), w=1.5
A3: 70(팀), 정시 → max(40, 70)=70        버킷(팀,필수),  w=1.0
활성 버킷 3개, base 합 = 0.28+0.42+0.12 = 0.82

성취도 = 90×(0.28/0.82) + 80×(0.42/0.82) + 70×(0.12/0.82) = 81.9512
성실성 = 3/3 × 100 = 100.0
최종   = 81.9512 × 0.7 + 100 × 0.3 = 87.3658 → 87.4
```

| | 성취도 | 성실성 | 최종 |
|---|---|---|---|
| 손계산 | 81.9512 | 100.0 | **87.4** |
| RoundScore | 81.9512 | 100.0 | **87.4** |

`graded=3 · ungraded=0 · total_count=3` (Aout 제외 확인)

### [C] partial (id 22) — 손계산 일치

```
A1: 60, 지각(due 08-18, 제출 08-19) → 60 - late_penalty 5 = 55, max(40, 55)=55
A2: 미제출, 선택 → 0
A3: 70(팀), 정시 → 70
성취도 = 55×(0.28/0.82) + 0×(0.42/0.82) + 70×(0.12/0.82) = 29.0244
성실성 = 2/3 × 100 = 66.6667      (A1 제출 + A3 팀제출, A2 미제출)
최종   = 29.0244 × 0.7 + 66.6667 × 0.3 = 40.3171 → 40.3
```

| | 성취도 | 성실성 | 최종 |
|---|---|---|---|
| 손계산 | 29.0244 | 66.6667 | **40.3** |
| RoundScore | 29.0244 | 66.6667 | **40.3** |

### [D] none (id 23) — 팀 제출 반영 확인

전부 개인 미제출이지만 팀 213 의 A3 제출(70)이 **팀원 전체에 반영**(BR-005).

```
A1: 미제출, 필수 → 10
A2: 미제출, 선택 → 0
A3: 팀 제출 70 → 70   (본인이 안 냈어도 팀 점수)
성취도 = 10×(0.28/0.82) + 0 + 70×(0.12/0.82) = 13.6585
성실성 = 1/3 × 100 = 33.3333
최종   = 13.6585 × 0.7 + 33.3333 × 0.3 = 19.56 → 19.6
```

RoundScore: `total=19.6 · ach=13.6585 · sinc=33.3333 · graded=1 · total_count=3 · team_included=True` ✔

### [E] 스코프 격리

Aout(`due 2026-09-01`, 회차 밖)에 full 이 100점 제출·채점했으나
→ full 의 `total_count=3`, 성취도·성실성 어디에도 안 섞임. ✔
