# 학생 성적 산출 정책 (v1)

**작성:** 2026-08-31 · **구현:** `apps/tutor/grading.py` + `apps/tutor/models.py::GradingPolicy`
**적용 범위:** 튜터 전용 (학생 화면 비노출). 실시간 계산 — 저장하지 않음.

> PRD/ERD 의 "final_score 집계 방식 오픈 퀘스천"에 대한 확정안. `Submission.final_score`(과제별 튜터 점수 캐시)는
> 그대로 두고, 그 위에 **학생별 종합 점수(0~100)** 를 얹는다.

---

## 1. 큰 그림

```
최종 점수 = 과제 성취도 × 0.7  +  성실성(제출률) × 0.3        (0~100, 소수 1자리)
```

- **과제 성취도 (70%)** — 튜터가 채점한 과제 점수를 영역별로 가중 합산
- **성실성 (30%)** — 마감된 과제를 얼마나 냈는지 (성실히 다 낸 학생 우대)

---

## 2. 과제 성취도 (70%)

### 2.1 4개 영역

과제를 **개인/팀 × 필수/선택** 으로 나눈 4개 영역. 각 영역의 기본 비중:

| 영역 | 비중 | 계산 |
|---|---|---|
| 개인 · 필수 | 28% | 개인(0.7) × 필수(0.4) |
| 개인 · 선택 | 42% | 개인(0.7) × 선택(0.6) |
| 팀 · 필수 | 12% | 팀(0.3) × 필수(0.4) |
| 팀 · 선택 | 18% | 팀(0.3) × 선택(0.6) |

- 개인 : 팀 = **7 : 3**
- 선택 : 필수 = **6 : 4** (선택 과제 영역이 더 크다 — 선택 과제를 열심히 한 학생 우대)

### 2.2 빈 영역 재정규화

해당 영역에 **과제가 하나도 없으면**(또는 아래 규칙으로 전부 제외되면) 그 영역의 비중을
나머지 영역에 비례 배분한다.

> 예 — 팀 과제가 전혀 없는 기수: 팀·필수(12%)·팀·선택(18%)이 빠지고
> 개인·필수 28% → 40%, 개인·선택 42% → 60% 로 재조정.

4개 영역이 전부 비면 → **최종 점수 미산출** (`—`).

### 2.3 영역 점수 = 중요도 가중평균

```
영역 점수 = Σ(과제 원점수ᵢ × 중요도ᵢ) / Σ(중요도ᵢ)
```

중요도(`Assignment.weight_tier`)는 **가중평균의 weight** 로만 쓴다 (점수에 직접 곱하지 않음):

| 중요도 | 배수 |
|---|---|
| 상 (HIGH) | 1.5 |
| 중 (MID) | 1.0 |
| 하 (LOW) | 0.5 |

### 2.4 과제별 원점수

| 상황 | 원점수 |
|---|---|
| 미제출 · 필수 | **10** |
| 미제출 · 선택 | **0** |
| 제출 · 미채점 | **영역 계산에서 제외** (+ "미채점 N건" 안내) |
| 제출 · 채점 완료 (튜터 점수 `e`) | 필수 `max(40, e − 지각감점)` · 선택 `max(20, e − 지각감점)` |

- **최저 보장점**: 필수 과제는 제출하면 최소 40점, 선택 과제는 최소 20점 (팀 과제도 동일).
- **지각 감점**: 마감 후 제출 시 `Assignment.late_penalty`(과제별, 튜터가 등록 시 설정) 만큼
  튜터 점수에서 차감. 단 최저 보장점 아래로는 못 내려간다.
- **미채점 제외**: 튜터가 아직 점수를 안 매긴 제출물은 성취도에서 빼고, 화면에 "미채점 N건" 표시.
  → 채점이 진행될수록 점수가 갱신됨. 채점된 과제가 하나도 없으면 최종 점수 미산출.
- **팀 과제**: 학생이 속한 팀의 제출물·튜터 점수를 팀원 전원이 동일하게 상속 (BR-005).
  팀이 없는 학생은 팀 영역 전체 제외 (재정규화).

---

## 3. 성실성 (30%)

```
성실성 = 제출한 과제 수 / 마감 지난 대상 과제 수 × 100
```

- 필수·선택 구분 없이 **전체 과제** 기준.
- 팀 과제는 "우리 팀이 냈으면 나도 제출한 것"으로 인정.
- **지각 제출도 제출로 인정** (성취도에서 감점은 별개).
- 마감 안 지난 과제는 분모에서 제외.

---

## 4. 계산 대상

- `due_at < now` 이고 **삭제되지 않은** 과제만.
- 마감 전 과제는 성취도·성실성 어디에도 포함하지 않음 (아직 제출 기회 있음).

## 7. 예시 계산

과제: 개인·필수 3개(중요도 중/중/상), 개인·선택 1개(중), 팀·필수 1개(중). 전부 마감됨.

| 과제 | 상황 | 원점수 |
|---|---|---|
| 필수A (중) | 제출·채점 90, 정시 | 90 |
| 필수B (중) | 미제출 | 10 |
| 필수C (상) | 제출·채점 50, 지각(감점 20) | `max(40, 50−20)` = 40 |
| 선택A (중) | 제출·채점 80 | 80 |
| 팀필수 (중) | 팀 제출·채점 85 | 85 |

- 개인·필수 = (90×1.0 + 10×1.0 + 40×1.5) / (1.0+1.0+1.5) = 160 / 3.5 = **45.71**
- 개인·선택 = 80×1.0 / 1.0 = **80.0**
- 팀·필수 = 85×1.0 / 1.0 = **85.0**
- 팀·선택 = 과제 없음 → **재정규화**: 개인·필수 .28, 개인·선택 .42, 팀·필수 .12 (합 .82)
  → 정규화 .341 / .512 / .146
- 성취도 = 45.71×.341 + 80.0×.512 + 85.0×.146 = 15.60 + 40.98 + 12.44 = **69.0**
- 성실성 = 4 제출 / 5 과제 × 100 = **80.0**
- **최종 = 69.0 × 0.7 + 80.0 × 0.3 = 48.3 + 24.0 = 72.3**

## 8. 결정 사항 요약 (rationale)

| 결정 | 이유 |
|---|---|
| 선택 미제출 = 0점 (분모 포함) | 분모 제외 방식은 "선택 안 한 학생 > 낮게 받은 학생" 역전이 생김. 0점 포함이면 "뭐라도 하면 이득". |
| 중요도 = 가중평균 weight (점수에 안 곱함) | 점수에 곱하면 100 초과·이중 반영. weight 로 쓰면 0~100 유지되고 "중요 과제 잘하면 유리/못하면 불리". |
| 미채점 = 제외 (블로킹 아님) | 튜터 채점이 다 끝나야 점수가 나오면 운영 초기에 전원 공란. 채점된 것만으로 내고 "N건 미채점" 표시. |
| 최종 점수 튜터 전용 | 학생에게 잠정 집계 점수를 노출하면 혼선. 학생은 과제별 튜터 점수만 봄 (기존 FR-014). |
| 상수 = DB 테이블 | 정책이 바뀔 수 있어 코드 배포 없이 admin 에서 조정 가능하게. |
